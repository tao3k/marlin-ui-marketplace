# Official & Community Plugins

Every plugin listed under `plugins` in [`../registry.json`](../registry.json) is built cleanly from its pinned `commit_sha` and signed exclusively by Official Marketplace CI.

## Priority Community & Ecosystem Categories

- **Git UI** (`developer-tools`): Interactive staging, branch graph, commit history, and hunk diff panels.
- **GitHub UI** (`developer-tools`): Pull request inbox, inline review comments, and Actions status monitors.
- **AI Workflows** (`ai-workflows`): Multi-agent run inspectors, memory triage, prompt evaluation benches.
- **Productivity** (`productivity`): Org-mode agendas, Kanban boards, calendar & time-block planners.
- **System Docks** (`system-dock`): Zero-WebView Go 1.27 WASI GPU clocks, telemetry gauges, and process watchers.
- **Mobile Packs** (`mobile-packs`): Declarative App Store 2.5.2-safe capture & companion overlays.

See [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for the exact PR checklist.
